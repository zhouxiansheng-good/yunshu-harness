# 记忆

0.6.12-preview.4 · 入口：会话输入栏 → 云舒 → 记忆。

## M00 · 自动记录与读取

- 对话公开内容自动记录；达到窗口阈值后自动归档。
- 新问题到来时，按相关性和上下文预算自动读取记忆。
- 本地索引在后台建立；索引不可用时保留关键词检索。
- 每轮结束后，后台使用当前回答模型从用户原话提炼普通记忆；不要求用户手动确认。失败保留任务，重试不重复写入。
- 点击“关闭自动记忆”后，不再保存新对话原话或启动提炼；已有存档仍可读取。重新开启后处理关闭前等待的任务，不补录关闭期间的对话。开关状态随存档区保存，重启后保持。
- 面板顶部显示自动记忆已保存、等待和重试轮数；“写入详情”显示原话保存失败和分段接续状态。
- 原话完整保存；长原话在索引中显示节选，点开原件可读取全部。核心事实、个人档案及观察更正仍由用户确认。
- 自动提炼通常每轮调用一次回答模型；长原话最多三次。使用的模型可能产生费用。

## M01 · 默认模板

- 核心事实提供交流语言、回复方式、协作偏好三类模板。
- 点击“使用…模板”，修改内容，再点击“添加事实”。
- 个人档案提供称呼、职业、所在地、语言、回复方式、协作方式与当前项目等字段。
- 点击“编辑档案”修改并保存；“取消编辑”不写入。
- “补充默认字段”保留已有值和扩展字段。
- 模板未保存时不参与检索，也不会写成用户事实。

## M02 · 查看与纠正

- 核心事实可编辑、撤回。
- 对话记录和长期归档可查看；笔记可编辑、撤回、查看历史。
- 自动提炼的普通记忆直接写入；仅选择人工复核路径时，“待确认”笔记才需要确认或拒绝。
- 核心事实、本地索引、工作区笔记与附件设置默认收起；展开后编辑、撤回或查看历史。
- “导出记忆 JSON”使用 v4 格式，包含记录、来源、观察、自动记忆任务与进度；恢复目标须为空。

## M03 · 存档区

- 云舒 → 记忆 → 存档区显示当前路径和详细文件位置。
- 在“切换存档区”输入新文件夹完整路径，点击“使用此存档区”。完整退出并重启 DeepSeek 后生效。
- 空文件夹会复制当前记忆、个人规则和媒体；已有云舒存档区直接启用，不覆盖原数据。
- 同一存档区内按需检索其他项目记忆；其他项目笔记可在面板查看。
- 切换位置前退出应用并备份当前存档。旧位置不会自动删除。

## M04 · 附件与备份

- “附件与备份”位于存档区之后，显示当前项目的保存状态与内容观察数量。
- 新附件自动保存；有问题时展开“处理附件问题”，补扫或补交仅有引用的附件。
- 当前项目备份与恢复在同一区域；恢复到新目录后不会自动切换存档区。
- 操作和限额见 media-guide.md。

记录与召回在插件启用时运行。新会话显示 0 条，不代表自动记录已关闭。
