# 附件与备份

0.6.12-preview.4 · 入口：会话输入栏 → 云舒 → 记忆 → 附件与备份。

## 附件

- 消息中的内联图片、音频、视频和文件自动保存到当前存档区。
- 外部网址和本地文件路径只保留引用，不自动下载。
- 附件状态显示已保存、待处理、需处理和内容观察数量。
- 正常状态下，检查和备份入口折叠；出现遗漏、失败或暂停时显示处理入口。
- 模型处理图片或音频并调用观察工具后，可保存带来源的内容描述；文件保存本身不等于内容识别。
- 来源撤回后，关联观察不再读取；已保存文件仍保留。

## 处理问题

1. 在“处理附件问题”点击“补扫遗漏附件”或“继续检查”。
2. 仍有“仅有引用”时，点击对应来源的“查看”。
3. 选择“目标附件”和本地文件，点击“确认补交”。
4. 点击“检查文件”核对保存状态；需要时点“重新检查”。

- 补交保留“用户补交”标记，不修改原始消息。
- 仅有引用的附件允许补交；内联附件使用补扫。
- 目标附件按来源编号定位；最近 30 条问题来源可直接查看。
- 文件为空、超过单文件上限或内容与已绑定附件不一致时不会覆盖已有文件。

## 备份与恢复

1. 展开“备份与恢复”，填写“新备份目录”，点击“创建备份”。
2. 恢复时填写“备份来源目录”和“新恢复目录”，点击“恢复备份”。
3. 恢复完成后按需切换存档区；恢复操作不会自动切换当前目录。

备份包含当前工作区的消息、观察、关联附件，以及共享的核心记忆和个人资料；不包含个人规则、情感状态、向量缓存和完整审计历史。恢复目标须为新目录。

## 限额

| 项目 | 默认值 |
| --- | ---: |
| 单个媒体文件 | 16 MiB |
| 媒体库总量 | 256 MiB |
| 单条原始消息 | 2 MiB |
